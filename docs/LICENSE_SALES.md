# TR Driver — ücretlendirme yok

TR Driver **tamamen ücretsiz** MIT açık kaynaktır. Koltuk paketi, yıllık ücret veya lisans anahtarı satışı yoktur.

Kullanıcı sayısı sınırı uygulanmaz. Varsayılan depolama kotası `DATA_DIR` disk kapasitesine göre belirlenir; Admin panelinden varsayılan ve kullanıcı kotası değiştirilebilir.
