# TR Driver Android

## Release APK (imzalı) — v0.4.0
`dist/android/TRDriver.apk`  
Web indirme: `/download/TRDriver.apk` (doğru MIME) veya `/apps/TRDriver.apk`

Sideloading’de “Play Protect / doğrulanmadı” uyarısı Play Store dışı kurulumlarda normaldir; APK **release imzalı**dır.

Güncelleme: eski sürümün üzerine kurun (`versionCode` artırılmış olmalı). İmza farklıysa önce kaldırıp yeniden yükleyin.

## Özellikler
- Üye ol / giriş / QR ile giriş
- Galeri yedek: `TR Photos / {cihazadı} / yıl / ay`, tek tek yükleme
- Video/müzik/resim önizleme (Authorization header ile stream)
- Arka plan müzik
- İkon: TR / Driver
