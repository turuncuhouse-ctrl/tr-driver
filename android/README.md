# TR Driver Android

## Release APK (imzalı)
`dist/android/TRDriver.apk`  
Web indirme: `/apps/TRDriver.apk`

Sideloading’de “Play Protect / doğrulanmadı” uyarısı Play Store dışı kurulumlarda normaldir; APK artık **release imzalı**dır (debug değil).

## Özellikler
- Üye ol / giriş / QR ile giriş
- Galeri yedek: `TR Photos / {cihazadı} / yıl / ay`, tek tek yükleme
- Medya önizleme + arka plan müzik
- Küçük resim önizlemeleri
